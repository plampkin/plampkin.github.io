# philip-lampkin.me

A simple personal site built with [Jekyll](https://jekyllrb.com).

## What lives where

| File | What it controls |
| --- | --- |
| `_config.yml` | Name, tagline, bio, header links, current position, previous positions, research interests |
| `_data/publications.yml` | Publications (grouped by year) |
| `_data/projects.yml` | Open-source projects |
| `assets/css/style.css` | All styling |
| `_layouts/default.html` | Page shell (head, fonts, footer, tab-switching script) |
| `index.html` | Page layout |
| `CNAME` | Custom domain (`philip-lampkin.me`) |
